# Guia de Setup Codex / Copilot (Antigravity)

Este adaptador contém diretrizes para a interação com modelos OpenAI Codex e integrações via GitHub Copilot.

## Integração com IDE

- As regras de projeto (`AGENTS.md`) devem ser lidas automaticamente pelo Copilot.
- Utilize comentários estruturados e JSDoc para auxiliar a conclusão de código em tempo real.

## Ignore e Contexto

- Copilot respeita o arquivo `.gitignore` do repositório por padrão.
- Para refinamentos de contexto no Copilot Chat, utilize referências diretas a arquivos via `#file`.
