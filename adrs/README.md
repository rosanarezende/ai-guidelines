# ADRs de Prompt Engineering (Micro-Decisões)

Esta pasta registra micro-decisões governamentais e de adoção de frameworks que
moldarão as habilidades dos agentes de IA.

Use ADR quando a decisão:

- Adotar uma nova Skill mandatória
- Configurar uma integração complexa via Servidor MCP (e.g. Supabase vs
  Pinecone)
- Alterar substancialmente o fluxo humano + IA em `AGENTS.md` ou
  `global-rules.md`

## Formato recomendado:

- contexto (Qual problema o agente não consegue resolver agora)
- decisão tomada
- impacto ou ação executada no agente
- resultado observado (A eficácia melhorou?)
- lições e gotchas
