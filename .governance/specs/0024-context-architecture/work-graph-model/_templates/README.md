# \_templates — ponte histórica, não fonte ativa

Este diretório fica apenas para preservar o caminho antigo usado pela v2.

A incubação Guilda preservou templates históricos em:

- `_archive/guilda-incubation-2026-07/backend/templates/` — templates operacionais da
  incubação que nasceu como `governance-demo`;
- `_archive/templates-v2/` — templates v2 arquivados para referência histórica.

Quando a P12 for consolidada no framework, a casa runtime dos templates deve ser a superfície
governada do core (`.core/governance/templates/`), não este diretório de pesquisa.
