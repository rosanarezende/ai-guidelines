# res-002 — cobertura: os campos do login cabem num schema?

> Data: 2026-06-28

**Questão(ões):** q1 (schema declarativo × regra imperativa).

**Evidência / achados:**

- Os campos do login (email · site · telefone) são **~90% cobertos** por regras nomeadas
  (required · email · pattern de telefone/URL).
- Os **~10% restantes** (ex.: telefone por país, validação cruzada entre campos) precisam
  de lógica custom → não cabem só no schema.

**Recomendação (escolha, bounded):** o schema cobre o comum; **manter o escape hatch** pros
~10% custom (reforça [[res-001]] por outro método). O humano decide.
