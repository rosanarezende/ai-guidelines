# res-004 — como os MFEs renderizam erro de form hoje

> Data: 2026-06-28

**Questão(ões):** q3 (estado controlado × render-prop/slot).

**Evidência / achados:**

- Scan dos MFEs consumidores: a **maioria** renderiza a mensagem de erro padrão (texto
  abaixo do campo) — poucos casos custom.
- Só **1 fluxo** precisa de erro com layout próprio (um banner agregado no topo).

**Recomendação (escolha, bounded):** estado controlado como default cobre o comum; um slot
opcional atende o caso custom. **Mas é baixa prioridade** — pode ficar sem decisão nesta
rodada (q3 segue respondida-sem-gate). O humano decide.
