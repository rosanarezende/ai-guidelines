# Arquivo historico do work-graph-model

Esta pasta guarda artefatos que continuam uteis como contexto, mas nao devem
concorrer com os documentos ativos da frente.

Regra de leitura:

- documentos na raiz de `work-graph-model/` sao os pontos ativos;
- `governance-demo/` e apenas um tombstone apontando para a extracao do produto
  Guilda;
- documentos nesta pasta sao historicos, prompts, handoffs, prototipos ou
  simulacoes substituidas;
- se um arquivo arquivado contradiz `model.yml`, `tracker.md`,
  `features.md`, `integration-catalog.yml` ou
  `GUILDA-EXTRACTION-DISPOSITION.md`, vence o documento ativo.
