# Public Landing Hero Candidate

This folder preserves the current generated public hero image candidate for Guilda Governance.

The same file is copied to `frontend/public/brand/heroes/public-workgraph-hero.png` so the Next app can render it through a stable public URL.

## Usage

- Use this image as a landing-page hero/background illustration.
- Do not use it as the Guilda Workgraph product icon.
- Keep `graph.png` / `graph-inverse.png` reserved for the Guilda Workgraph icon family.
- This candidate intentionally leaves more empty space on the left so text can be overlaid on the hero.
