# Guilda Product Icon Set

This folder preserves the first selected product icon family for Guilda Governance.

The same files are copied to `frontend/public/brand/icons/` so the Next app can render them through stable public URLs.

## Usage

- `governance.png` / `governance-inverse.png`: Guilda Governance mark for light and dark surfaces.
- `graph.png` / `graph-inverse.png`: Guilda Workgraph visual layer.
- `host.png` / `host-inverse.png`: Guilda Host, the Git-backed governance home.
- `flow.png` / `flow-inverse.png`: `guilda flow`, the future CLI surface.
- `cup.png` / `cup-inverse.png`: Guilda Cup, the Contextual Work Partner.

The `*-inverse.png` files are preferred on dark green or dark graphite surfaces. The non-inverse files are preferred on off-white or light surfaces.
