# Prompt — Hero Da Página Pública

Use este prompt em geradores de imagem quando precisar criar a imagem principal da
página pública do Guilda Governance.

```text
Create a refined product hero illustration for "Guilda Governance", an open-source work governance platform.

Core narrative:
- People decide; the system supports.
- The product connects decisions, evidence, responsibilities, work areas, repositories, integrations, and a Git-backed governance host.
- It should feel like a modern craft guild for digital work: trust, shared responsibility, context, and coordinated flow.
- It must not look like AI making decisions for humans.

Visual direction:
- Use the existing Guilda visual language: deep forest green, sage green, warm off-white, graphite, and muted brass.
- The composition should be an abstract workgraph landscape, not a literal dashboard screenshot.
- Use organic but precise connected nodes: irregular rounded hexagonal work areas, a muted brass human decision node, evidence/context nodes, risk/guardrail nodes, and an outward flow line that suggests repositories, integrations, and the governance host.
- The image should look useful for a public product landing page, not decorative stock art.
- Show a sense of teamwork and coordinated craft without drawing medieval castles, shields, swords, crowns, torches, scrolls, robots, generic AI stars, neon circuits, or mascots.
- Avoid using the letter G as the main symbol; the workgraph should carry the meaning.

Layout requirements:
- Wide horizontal hero image, 16:9 or wider.
- Leave clean negative space on the left side for headline text if needed.
- Keep the right side richer with the workgraph network.
- The graph should remain legible at web sizes.
- Use flat/vector-like shapes with subtle depth; no photorealistic 3D, no heavy gradients, no busy background.

Semantic mapping:
- Brass circle = human decision point.
- Deep green blocks = work areas, teams, initiatives, domains.
- Sage/off-white blocks = context, evidence, documents, insights.
- Graphite block = policy, risk, guardrail, constraint.
- Thin dark green lines = evidence trails and responsibility links.
- One outward muted brass/green path = work continues into repositories, integrations, and governance host.

Tone:
- calm, precise, trustworthy, open-source, human-centered, sophisticated, not corporate bureaucracy.

Output:
- Produce a clean hero illustration only.
- Do not add fake UI text, fake navigation, labels, watermarks, or "Product Name" placeholders.
- Do not include a cup/trophy icon in this hero; Guilda Cup is a separate contextual work partner surface.
```
