# Work Graph Model Reviews

Esta pasta guarda revisões e auditorias versionadas da frente `work-graph-model`.

Use aqui quando o artefato revisado atravessa modelo, simulação, app, backend, ferramentas ou
decisões de adoção. Revisões locais de uma superfície muito específica podem referenciar arquivos
da `governance-demo`, mas a evidência de revisão não pertence à aplicação.

Diretrizes:

- não tratar reviews como SSOT do modelo; o SSOT continua sendo `model.yml`;
- não tratar reviews como backlog de produto; próximos passos executáveis devem ir para
  `governance-demo/NEXT-STEPS.md`, `features.md` ou documentos funcionais apropriados;
- manter achados com fato, interpretação, severidade e recomendação;
- quando um review for reconciliado, registrar a decisão no documento governado correto.
