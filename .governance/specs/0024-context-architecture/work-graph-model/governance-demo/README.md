## Por que este tombstone existe

O `work-graph-model` foi o laboratorio governado onde a Spec 0024 testou o
modelo de trabalho como grafo tipado: decisoes, evidencias, responsabilidades,
contratos, outcomes, repositorios, gates e revisoes. A aplicacao Guilda nasceu
desse dogfood, mas o objetivo do checkpoint atual do `ai-guidelines` continua
sendo framework: artifact taxonomy, `pre-coding-review`/model-review,
research-index e disposicao honesta de artefatos.

A ponte entre as QRDs criadas durante essa incubacao e o objetivo do checkpoint
esta registrada em
[`../GUILDA-QRD-PRESERVATION-MATRIX.md`](../GUILDA-QRD-PRESERVATION-MATRIX.md).

Este tombstone existe para preservar essa fronteira:

- o historico da incubacao nao deve ser perdido;
- o produto vivo nao deve ser reativado acidentalmente neste repo;
- PR #45 nao deve ser lido como validacao de v1 da Guilda;
- qualquer evolucao de tela, desktop, site, auth, design system ou distribuicao
  pertence ao repo `guilda`.

Autoridade atual:

- o produto Guilda evolui no repo `guilda`;
- o `ai-guidelines` conserva o modelo, a pesquisa e a evidencia historica que
  deram origem ao produto;
- este caminho existe como tombstone para impedir reativacao acidental da demo.

Nao rode builds, testes, formatacao ou novas implementacoes de Guilda a partir
desta pasta.
