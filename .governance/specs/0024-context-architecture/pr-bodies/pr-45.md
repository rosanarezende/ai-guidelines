## Resumo

Este PR organiza como o repositório diferencia pesquisa, revisão, decisão, projeção visual, dogfood e legado. Hoje esses artefatos podem se misturar e parecer ter a mesma autoridade, o que aumenta o risco de humanos e agentes seguirem a fonte errada.

A entrega esperada é uma taxonomia aplicável e verificável, além de um contrato para revisão antes do código. O objetivo é reduzir ambiguidade: cada artefato deve declarar o que é, qual autoridade tem e onde entra no fluxo.
