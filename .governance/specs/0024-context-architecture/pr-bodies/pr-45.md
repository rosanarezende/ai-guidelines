## Resumo

Este PR consolida a frente da Spec 0024 que modela o trabalho como grafo tipado e agora entrega uma simulação operacional mais próxima de uso real: org acme file-first, repos adotados com código MVP, resolvers fail-closed, backends derivados e uma primeira superfície React/Next + Material UI.

A entrega mais recente amplia o app ponta-a-ponta: ele lê a runtime v3 server-side, mostra planejamento/intake/execução/contratos/outcomes/repos/operação e envia comandos governados para dry-run/execute sem editar YAML diretamente. O fluxo mínimo agora cobre intake → triage → gate → ativação → breakdown → repo-work ack → contract revision proposal → outcome → verdict, além de incident declaration e break-glass governado.

Esta atualização também sanitiza a documentação da frente work-graph: registra decisões fechadas, corrige status stale da v3, cria o catálogo versionado de integrações externas e deixa explícito que adapters são opcionais para evidência/importação/projeção — não SSOT paralelo.

- Comandos mutáveis mecanizados nesta fatia: `proposal.create`, `triage.save`, `gate.decide`, `intent.activate`, `breakdown.apply`, `repo-work.ack`, `contract.propose-revision`, `outcome.publish`, `verdict.accept`, `incident.declare` e `policy.break-glass`, com `base-revision`, authority resolvida, idempotency, nonce, escrita YAML e event-log append-only.
